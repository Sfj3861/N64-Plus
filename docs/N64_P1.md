# N64_P.1

This iteration refreshes the Android library interface with a dark card-based layout, clearer system selection, library controls, game metadata, and a selection action.

## Current SNES status
The SNES folder scanner and selection flow remain functional. **Playback is not implemented in this build.** The current JNI component only probes for a core shared library; it lacks the Libretro frontend environment, callbacks, content loading, frame loop, input mapping, audio output, and rendering surface. Selecting Play currently reports this limitation rather than pretending to start a game.

## Next engine work
Implement and test a licensed Libretro core integration, Android frontend callbacks, SAF content handling, GLES rendering, audio, input, and lifecycle cleanup before advertising playable emulation.
